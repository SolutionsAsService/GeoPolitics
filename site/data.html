Data

Where every thread comes from.

Sources

  • This repository's data/ folder: 179 organisations with a members field, plus language, religion, defence and tax files. MIT licence.
  • Wikidata (CC0), queried by _src/fetch_wikidata.py; each result is kept in data/sources/wikidata/ with its query and fetch time: countries and capitals (2026-10-31), memberships (2026-10-31), official languages (2026-10-31), games hosts (2026-10-31), World Heritage Sites (2026-10-31).
  • Country shapes: Natural Earth 1:110m (public domain) via world-atlas 2.0.2, in data/sources/countries-110m.json. Projection: Natural Earth I, computed at build time.

Repairs

7 files did not parse when this site was built. Each was repaired, changing syntax only except where noted:

AmericanOrgs.json: Mercosur's establishedBy repeated the keys treaty and year inside one object and missed a comma; it is now a list of two treaties, so neither is lost.

Languages/French.json: a bare string inside the Writing System object became the pair "Braille": "French Braille".

Languages/Portuguese.json: removed a trailing comma after the Lusophones list.

Languages/Arabic.json: removed a references list of placeholders ("Source 1", "Source 2", "Source 3", "..."); it cited nothing.

Languages/Hindi.json: removed a references list of placeholders ("Source 1", "Source 2", "Source 3", "..."); it cited nothing.

TransatlanticOrgs.json: the file stopped after its first entry with a dangling comma; closed the list and the object (one entry, the OEI, is all the file held).

DefenseAgreements/UKDefense.json: the file held two JSON objects one after another; merged into one object with the keys UKDefense, NonEUDefenceCooperation (no key was in both).

Names resolved by hand

  • "China" is People's Republic of China (CHN): Wikidata names the state "People's Republic of China".
  • "Brunei Darussalam" is Brunei (BRN): the state's official short name.
  • "Cabo Verde" is Cape Verde (CPV): the state's official name since 2013.
  • "Korea (Republic of)" is South Korea (KOR): ISO's form of South Korea's name.
  • "Venezuela (suspended)" is Venezuela (VEN): Mercosur lists Venezuela as suspended; the thread keeps it and the organisation's record says so.
  • "Soviet Union": dissolved 1991; placed at Moscow.

How to read a thread

A thread visits its members' capitals from west to east (games: in hosting order). Its route and length are geography, not weight; only which countries it passes through is data. A knot's area is proportional to the threads through it.

Built from the GeoPolitics data repository and Wikidata (CC0); map shapes from Natural Earth via world-atlas 2.0.2. Every count on this site is computed from the data at build time: facts.json. What could not be placed is listed on the Data page.
